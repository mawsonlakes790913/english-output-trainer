## 学習完了画面の実装

### 実装内容

- 最後の問題を解き終えた後の遷移先が存在しなかったため、学習完了画面 `complete.html` と、それを表示するための `CompleteController` を作成した。
- 学習完了画面は、学習終了を知らせるメッセージと Home 画面へ戻るボタンのみを配置したシンプルな構成としたため、実装自体は非常に容易であった。

- また、`study.html` 側では最終問題に到達した際、「次の問題へ」ボタンの代わりに学習完了画面へ遷移する「Complete」ボタンを表示するよう変更した。

- 元々の「次の問題へ」ボタンは以下のように、次のページが存在する場合のみ表示される仕組みとなっていた。

```html
<a th:if="${page.hasNext()}"
   th:href="@{/study(page=${page.number + 1},size=1)}"
   class="btn btn-primary">
    次の問題へ
</a>
```

- この仕組みを応用し、「次のページが存在しない場合」にのみ表示されるボタンを追加することで、学習完了画面への遷移を実現した。

```html
<a th:if="${!page.hasNext()}"
   th:href="@{/complete}"
   class="btn btn-success">
    Complete
</a>
```

- `Page` オブジェクトの `hasNext()` を利用することで、現在の問題が最終問題かどうかを簡単に判定できることが分かった。

### 所感

- 学習完了画面そのものの実装は難しくなかったが、「最後の問題だけボタンの挙動を変える」という実装を通じて、`Page` オブジェクトが持つページング機能の便利さを改めて実感した。
- これにより、問題数が増減した場合でもコードを変更することなく、最終問題の判定を自動で行えるようになった。
