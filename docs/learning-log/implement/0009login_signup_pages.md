# 学習ログ：ログイン画面・新規登録画面の作成

## 概要

ログイン画面および新規登録画面を作成した。

現時点ではログイン機能やユーザー登録機能そのものは実装しておらず、画面遷移および入力フォームのレイアウト作成のみを行った。

また、前回作成した共通レイアウトを適用し、アプリケーション全体で統一感のある画面構成となるようにした。

---

## 実装内容

### LoginControllerの作成

ログイン画面へ遷移するためのControllerを作成した。

```java
@Controller
public class LoginController {

    @GetMapping("/login")
    public String getLogin() {
        return "login";
    }
}
```

---

### SignupControllerの作成

新規登録画面へ遷移するためのControllerを作成した。

```java
@Controller
public class SignupController {

    @GetMapping("/signup")
    public String getSignup() {
        return "signup";
    }
}
```

---

### ログイン画面の作成

ログイン画面を作成した。

入力項目は以下の2項目である。

- ユーザーID
- パスワード

また、新規登録画面へのリンクを配置した。

Bootstrapのフォーム関連クラスを利用することで、CSSをほとんど記述せずに見やすいフォームを作成できた。

---

### 新規登録画面の作成

新規登録画面を作成した。

入力項目は以下の3項目である。

- ユーザーID
- パスワード
- パスワード（確認）

また、ログイン画面へのリンクを配置した。

こちらもBootstrapのフォーム関連クラスを利用し、ログイン画面と統一感のあるレイアウトとした。

---

## 所感

今回はあまり苦戦したポイントや頭を使ったポイントはなかった。

理由として、このアプリは英作文の学習アプリであり、一般的な業務アプリケーションと比較するとユーザー入力の種類や量が少ないためである。

また、現時点ではログイン機能そのものやユーザー登録機能そのものを実装したわけではなく、画面を作成した段階に過ぎない。

そのため、今回は主にBootstrapを利用したフォーム作成と画面遷移の確認が中心となった。

一方で、今後実際にユーザー情報を登録・認証する仕組みを実装する際には、

- 入力値の受け取り
- バリデーション
- DBへの登録
- DBからの取得
- パスワード管理

など、考慮すべき点が大幅に増えると予想される。
